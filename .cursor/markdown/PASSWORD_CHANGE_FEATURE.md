# 密码修改功能文档

## 功能概述

密码修改功能允许已登录用户更改其账户密码。此功能遵循最佳安全实践，包括密码验证、强度检查和防暴力破解措施。

## 技术实现

### 前端实现

1. **页面路径**: `/profile/password`
2. **主要组件**: `ChangePasswordPage`
3. **表单字段**:
   - 当前密码
   - 新密码
   - 确认新密码
4. **客户端验证**:
   - 所有字段必填
   - 新密码与确认密码匹配
   - 新密码长度至少8位

### 后端实现

1. **API端点**: `/api/auth/password`
2. **HTTP方法**: POST
3. **请求参数**:
   - `currentPassword`: 当前密码
   - `newPassword`: 新密码
   - `confirmPassword`: 确认新密码
4. **安全措施**:
   - 频率限制：每10分钟最多5次修改密码请求
   - 身份验证：验证用户是否已登录
   - 密码验证：验证当前密码是否正确
   - 密码强度检查：使用`validatePasswordStrength`函数
   - 防止重复使用相同密码

## 数据库更新

1. **表**: `users`
2. **字段**:
   - `password_hash`: 使用PBKDF2算法+随机盐值哈希后的密码
   - `updated_at`: 自动更新为当前时间戳

## 安全特性

1. **防暴力破解**:
   - API频率限制
   - 安全的错误消息（不泄露用户存在与否）
   
2. **密码哈希**:
   - PBKDF2算法（100,000次迭代）
   - 随机盐值
   - SHA-512哈希函数
   
3. **密码强度要求**:
   - 最小长度：8位
   - 包含数字
   - 长度上限：128位
   
4. **安全错误处理**:
   - 统一错误格式
   - 不泄露敏感信息

## 用户流程

1. 用户从个人资料页面点击"修改密码"
2. 用户填写当前密码和新密码
3. 提交表单
4. 后端验证当前密码是否正确
5. 检查新密码是否符合强度要求
6. 更新密码
7. 返回成功消息

## 错误处理

系统提供多种错误反馈:

1. **验证错误**:
   - 当前密码不正确
   - 新密码与确认密码不匹配
   - 新密码不符合强度要求
   
2. **系统错误**:
   - 数据库连接异常
   - 服务器内部错误
   
3. **安全错误**:
   - 请求频率过高
   - 未授权访问

## 测试场景

1. **成功场景**:
   - 使用正确的当前密码和符合要求的新密码
   
2. **失败场景**:
   - 当前密码错误
   - 新密码不符合强度要求
   - 新密码与确认密码不匹配
   - 新密码与当前密码相同
   - 未登录用户尝试访问
   - 短时间内多次尝试修改密码
